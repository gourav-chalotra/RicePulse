Reference note: Discoloration ≤ 1%, broken/fragmented grains ≤ 5%, grain size ≥ 7 mm, moisture ≤ 14%, humidity ≤ 65% RH and temperature ≤ 30°C are shown as RicePulse reference/target values. Humidity and temperature are storage/measurement-environment references, not Basmati-specific FSSAI quality limits. The 7 mm grain-size value is a practical reference; Basmati standards can use specific average kernel-size requirements.
